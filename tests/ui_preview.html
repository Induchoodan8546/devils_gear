DEVIL’S GEAR

EXOTIC MAGICK · T-Embed 320×170 preview

This is a clickable mock of the firmware UI. The real binary only runs on a LilyGO T-Embed CC1101. Encoder left/right, click to select, Esc to go back.

Build

$env:PLATFORMIO_CORE_DIR = "D:\pio"
python -m platformio run -e lilygo-t-embed-cc1101

Host tests

python tests/test_devils_gear.py

Flash (hold BOOT, tap RESET, release BOOT)

python -m platformio run -e lilygo-t-embed-cc1101 -t upload

# or:
python -m esptool --chip esp32s3 --baud 921600 write_flash 0x0 firmware/DevilsGear-lilygo-t-embed-cc1101.bin

Serial monitor

python -m platformio device monitor -e lilygo-t-embed-cc1101
